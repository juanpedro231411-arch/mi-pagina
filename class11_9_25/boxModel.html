Box Model

Layout

  • Es la geometria de los elementos que define: el tamano, la separacion entre elemntos adyascentes, la posicion en la que se va a dibujar el elemento.

  • Propiedades: width y heght, el ancho y el alto

Elementos de linea(inline) y bloque (block)

Caracteristicas inline

  1. No crean nuevas lineas para cada elemento
  2. No se puede definir el ancho ni el alto
  3. Ele ancho se ajusta de acuerdo al contenido

Caracteristicas block

  1. Crean una linea para cadd elemento
  2. Ocupan todo el espacio horizontal disponible
  3. Estos si tienen un ancho y alto
