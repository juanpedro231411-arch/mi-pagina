Box Model o modelo de caja

El box model es el algoritmop a traves el cual el navegador dibuja las cajas en la pantalla solo se aplica a los elementos de bloque, cuenta con tres elementos

  1. Contenido-->content-bos
  2. Separacion entre el contenido y el borde--> padding-box
  3. Borde--> border-box

Tambien es necesario mencionar el margen que es una propiedad externa e indica la separacion entre cajas, la propiedad es el margin, ejemplo
