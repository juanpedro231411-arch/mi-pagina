Selectores

Selectores Sencillos

1. Selector Universal

Selecciona todos los documentos del documento web, se representa por *

2. Selectores de tipo o elemento

Este es el selector mas sencillo ya que simplemete es una etiqueta de HTML

3.Selector de Clase

Una clase es un atributo de un elemnto o etiqueta de HTML o XML. Este es el mas recomnedable para dar estilos ya que puede ser reutilizado

4.Selector por Id

Un id es un atributo de un elemento o etiqueta de HTML o XML. Su uso es mas recomendable para JS, ya que no puede ser utilizado en css.

Selectores Compuestos

Para este tipo de selectores hay mas de un selevtor combinado

Selectores Agrupados

Todos los selectores estan agrupados por el caracter ,

Selectores descendientes

indican que es un elemento hijo nieto, etc. se agrupan con un espacioejemplo:

  • Lista 1
  • Lista 2
  • Lista 3
  • Lista 4
  • Lista 5(final)
